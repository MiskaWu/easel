# 用 easel 生圖

easel 透過官方 Codex 用使用者的 ChatGPT 額度生圖。一律走 `new`、`revise` 這兩個工具，不要直接呼叫 `codex`。

## 流程

1. 把需求寫成結構化提示詞：用途、素材類型、主體、風格、構圖、尺寸、禁止事項。尺寸和畫質只能寫在提示詞裡，工具沒有參數。
2. 新素材用 `new`，素材名用小寫英數與連字號。遊戲角色、圖示這類要去背的，把 `transparent` 設成 `true`。
3. 修改用 `revise`，要求寫明「保留什麼、改什麼」。預設以最新版為底；使用者說要回到某一版才指定 `base`。
4. 畫好後用 Read 看圖，對照要求逐項自檢，再用 `self_check` 記錄。結論寫成一句話，面板會顯示給使用者看。
5. 不合格就用 `revise` 自動修改，最多 2 次，之後交給使用者判斷。不要一直重畫，每張都在花使用者的額度。
6. 最後告訴使用者哪個素材畫好了，請他到 `/easel` 面板審稿。

## 規則

- 核准和退回是使用者的決定，你不代替他按。
- 想看素材與額度現況用 `status`。
- 額度用完或 Codex 沒登入時，工具會拒絕並說明原因，照著告訴使用者。
